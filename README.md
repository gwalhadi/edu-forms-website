# منصة نماذج المعلمات — النسخة الثابتة (GitHub Pages + Firebase)

موقع مجاني بالكامل لتعبئة النماذج المدرسية وتنزيلها PDF بنفس التصميم الرسمي.

- **المعلمات:** يفتحن الرابط بدون تسجيل دخول ← يخترن النموذج ← يعبئنه ويوقّعن ← يعاينّه بحجم A4 ← ينزّلن PDF.
- **أنتِ فقط:** تدخلين لوحة التحكم (`admin.html`) بالبريد وكلمة المرور، وتضيفين النماذج وتعدّلينها وتنشرينها وتوقفينها وتحذفينها.
- **نماذج من ملف PDF جاهز (جديد):** ترفعين ملف PDF، فيكتشف الموقع أماكن التعبئة تلقائيًا، وتراجعينها (تحريك، تكبير، إضافة، حذف)، ثم تعبّئ المعلمة وتنزّل الملف **بنفس تصميم الملف الأصلي تمامًا**.
- **الخصوصية:** إجابات المعلمات وتواقيعهن وملفات PDF **لا تُرسل ولا تُحفظ في أي خادم**؛ كل شيء يتم داخل المتصفح. المسودات تُحفظ على جهاز المعلمة فقط.

---

## دليل النشر خطوة بخطوة

### الجزء الأول: إعداد Firebase (مرة واحدة)

1. ادخلي إلى https://console.firebase.google.com بحساب Google ← **Create a project** ← اكتبي اسمًا (مثل `edu-forms`) ← يمكنك إيقاف Google Analytics ← **Create project**. الخطة المجانية (Spark) هي الافتراضية، لا تضيفي بطاقة دفع.
2. **قاعدة البيانات:** من القائمة الجانبية **Build ← Firestore Database ← Create database** ← اختاري موقعًا قريبًا (لا يمكن تغييره لاحقًا) ← اختاري **Start in production mode** ← **Create**.
3. **تسجيل الدخول:** **Build ← Authentication ← Get started ← Sign-in method ← Email/Password** ← فعّلي الخيار الأول فقط ← **Save**.
4. **حسابك:** **Authentication ← Users ← Add user** ← اكتبي بريدك وكلمة مرور قوية (١٠ أحرف أو أكثر) ← **Add user**. ثم انسخي القيمة في عمود **User UID** (سلسلة أحرف وأرقام طويلة) واحتفظي بها.
5. **منع إنشاء حسابات أخرى:** **Authentication ← Settings ← User actions** ← أزيلي علامة **Enable create (sign-up)** و **Enable delete** ← **Save**.
6. **إعدادات الموقع:** اضغطي رمز الترس ⚙️ ← **Project settings ← General** ← في أسفل الصفحة **Your apps** اضغطي رمز الويب `</>` ← اكتبي اسمًا ← **لا** تفعّلي Firebase Hosting ← **Register app**. سيظهر كود فيه `firebaseConfig`؛ انسخي القيم (apiKey و authDomain و projectId …).
7. **قواعد الأمان:** افتحي الملف `firebase/firestore.rules` في هذا المجلد، واستبدلي `PASTE_ADMIN_UID` بالـ User UID من الخطوة ٤. ثم في Firebase: **Firestore Database ← Rules** ← احذفي الموجود والصقي محتوى الملف كاملًا ← **Publish**.

### الجزء الثاني: ربط الموقع بمشروعك

افتحي الملف `js/firebase-config.js` بأي محرر نصوص (مثل Notepad) والصقي القيم من الخطوة ٦ بدل كل `PASTE_...`، والصقي الـ User UID في `adminUid`. احفظي الملف.

> هذه القيم ليست كلمات مرور؛ Firebase مصمم لتكون ظاهرة في المتصفح. الحماية الحقيقية في قواعد الأمان التي تسمح لحسابك وحده بالتعديل.

### الجزء الثالث: النشر على GitHub Pages

1. أنشئي حسابًا في https://github.com (إن لم يكن لديك).
2. اضغطي **+** ← **New repository** ← الاسم مثل `edu-forms` ← اختاري **Public** (النشر المجاني يتطلب ذلك، ولا يوجد في الملفات أي سر) ← **Create repository**.
3. في صفحة المستودع اضغطي **uploading an existing file** ← اسحبي **محتويات** هذا المجلد (الملفات والمجلدات نفسها، وليس المجلد الأب) ← **Commit changes**.
4. **Settings ← Pages** ← تحت **Build and deployment** اختاري **Deploy from a branch** ← الفرع `main` والمجلد `/ (root)` ← **Save**.
5. انتظري دقيقة أو دقيقتين ثم حدّثي الصفحة؛ سيظهر الرابط: `https://اسم-المستخدم.github.io/edu-forms/`
6. ارجعي إلى Firebase: **Authentication ← Settings ← Authorized domains ← Add domain** وأضيفي `اسم-المستخدم.github.io`.

### الجزء الرابع: أول تشغيل

1. افتحي `https://اسم-المستخدم.github.io/edu-forms/admin.html` وسجّلي الدخول.
2. اضغطي **نقل النماذج الحالية**: تُنقل النماذج الأربعة وهوية المدرسة والشعار كما كانت.
3. جرّبي من جوالك: افتحي رابط الموقع، عبّئي نموذجًا، ونزّلي PDF.
4. أرسلي رابط الموقع للمعلمات (بدون `admin.html`).

بعد ذلك كل تعديل على النماذج يتم من لوحة التحكم ويظهر فورًا، **بدون إعادة رفع أي ملف**.

## تحديث موقع منشور مسبقًا (إضافة نماذج PDF)

> النماذج الحالية وقاعدة البيانات وإعداداتك لا تتغير. ملف `js/firebase-config.js` **غير موجود في حزمة التحديث عمدًا** حتى يبقى ملفك الحالي كما هو.

1. **قواعد الأمان (مرة واحدة):** Firebase Console ← **Firestore Database ← Rules**. افتحي الملف `firebase/pdf-rules-addition.txt`، وانسخي الجزء الذي فيه، والصقيه **فوق** السطر `// Everything else is closed.` دون تغيير أي شيء آخر ← **Publish**.
2. **رفع الملفات:** في مستودع GitHub ← **Add file ← Upload files** ← اسحبي **محتويات** مجلد التحديث (الملفات والمجلدات) ← **Commit changes**. سيستبدل GitHub الملفات القديمة بالجديدة ويضيف الجديدة، ويبقى `js/firebase-config.js` كما هو.
3. انتظري دقيقة أو دقيقتين، ثم افتحي لوحة التحكم واضغطي **Ctrl + Shift + R** (أو حدّثي الصفحة في الجوال) لتحميل النسخة الجديدة.
4. ستجدين زر **«نموذج من ملف PDF»** في «إدارة النماذج».

## نماذج PDF الجاهزة

1. **إدارة النماذج ← نموذج من ملف PDF** ← اختاري الملف (حتى ١٠ م.ب).
2. يكتشف الموقع تلقائيًا (داخل المتصفح، بدون أي خدمة مدفوعة):
   - حقول PDF التفاعلية إن كانت موجودة في الملف.
   - الخطوط المنقطة `.......` والشرطات `_____` (مع اسم الحقل المكتوب بجانبها).
   - السطور الفارغة، والسطور المتتالية للملاحظات (حقل متعدد الأسطر).
   - الخانات الفارغة في الجداول (ويُسمّى الحقل من رأس العمود ورقم الصف).
   - المربعات الصغيرة ☐ (تصبح حقل علامة ✓).
   - ويخمّن النوع من الاسم: «التاريخ» ← تاريخ، «التوقيع» ← توقيع، الخانة الكبيرة ← نص طويل.
3. **راجعي الحقول على الصفحة:** اضغطي أي مربع لتعديل اسمه ونوعه وحجم الخط والمحاذاة، اسحبيه لتحريكه، واسحبي النقاط على أطرافه لتغيير حجمه، واحذفي الزائد (زر الحذف أو مفتاح Delete).
4. **إضافة حقل يدويًا** (عندما لا يُكتشف تلقائيًا، أو للملفات الممسوحة ضوئيًا): «إضافة حقل» ثم ارسمي مربعًا في المكان الفارغ.
5. «نص تجريبي» يعرض نصًا داخل الحقول لتتأكدي من حجم الخط، و«تجربة النموذج» يتيح التعبئة والتنزيل التجريبي.
6. من «الإعدادات العامة» اكتبي عنوان النموذج، ثم **حفظ ونشر**.

المعلمة ترى الحقول كنموذج عادي (يعمل على الجوال)، ثم «معاينة وتنزيل PDF» فتظهر صفحات الملف الأصلي وعليها إجاباتها، وتنزّله. الملف الأصلي لا يتغير: تُضاف الكتابة فوقه فقط.

**ملاحظات:**
- يُحفظ الملف الأصلي الفارغ في Firestore مقسّمًا إلى أجزاء (لأن Firebase Storage غير متاح مجانًا للمشاريع الجديدة). إجابات المعلمات **لا تُحفظ** إطلاقًا.
- يُحفظ الملف الفارغ في متصفح المعلمة بعد أول فتح، فلا يُعاد تحميله كل مرة (توفير للحد المجاني).
- الملفات المحمية بكلمة مرور لا تُقبل: احفظيها أولًا بدون حماية (طباعة ← حفظ بتنسيق PDF).
- الملفات الممسوحة ضوئيًا: تُكتشف السطور والخانات والمربعات غالبًا، لكن بلا أسماء؛ اكتبي أسماء الحقول بنفسك.
- لاستبدال الملف بنسخة معدّلة مع الإبقاء على الحقول: «استبدال ملف PDF» داخل المحرر.
- النسخة الاحتياطية وتصدير JSON يتضمنان الملف الأصلي، فلا يضيع شيء عند الاستعادة.
- حذف نموذج PDF يحذف ملفه الأصلي أيضًا، إلا إذا كانت نسخة أخرى من النموذج تستخدمه.

## حدود يجب معرفتها

- **ملف PDF من زر «تنزيل PDF»** مطابق للتصميم الأصلي (نفس الخط والجداول والألوان والترويسة وترقيم الصفحات وتكرار رؤوس الجداول)، لكنه يتكون من صور عالية الدقة للصفحات، لذلك **النص فيه غير قابل للتحديد أو البحث**، وحجمه تقريبًا ٣٠٠ ك.ب – ١ م.ب للصفحة. للحصول على PDF نصي استخدمي زر **«طباعة»** ثم **«حفظ بتنسيق PDF»** (الأفضل في Chrome أو Edge على الحاسب).
- إذا تعذر التنزيل في متصفح قديم (خاصة Safari قديم على iPhone) يظهر تنبيه يوجّه إلى زر «طباعة».
- **لا توجد إرسالات للإدارة داخل الموقع:** المعلمة تنزّل الملف وترسله بالطريقة المعتادة (بريد، واتساب، منصة المدرسة). هذا هو المقصود لأن البيانات لا تُحفظ في أي خادم.
- **رمز دخول المعلمات أُزيل:** أي شخص لديه الرابط يرى النماذج المنشورة (الصفحات مُعلّمة لعدم الظهور في محركات البحث).
- **توقيع المديرة والختم:** إذا فعّلتِ إدراجهما في ملفات المعلمات تصبح صورتاهما قابلتين للتنزيل لأي شخص لديه الرابط. الوضع الافتراضي: غير مفعّل.
- **نماذج PDF:** الكشف التلقائي لا يقرأ الكتابة داخل الصور (لا يوجد تعرف ضوئي OCR لأنه يحتاج خدمة خارجية)، لذلك في الملفات الممسوحة ضوئيًا اكتبي أسماء الحقول يدويًا. نماذج Word/Excel: احفظيها PDF أولًا ثم ارفعيها.
- **حدود الخطة المجانية Spark:** ٥٠٬٠٠٠ قراءة و٢٠٬٠٠٠ كتابة يوميًا — تكفي أضعاف ٣٠ معلمة. إذا تجاوزها أحد عمدًا يتوقف عرض النماذج مؤقتًا حتى اليوم التالي، **بدون أي تكلفة**.
- **المسودات** محفوظة في متصفح المعلمة فقط؛ مسح بيانات المتصفح يحذفها.
- **حجم الصور:** تُصغّر تلقائيًا عند الرفع (حتى ~٧٠٠ ك.ب لكل صورة).
- الروابط القديمة بصيغة `/f/اسم-النموذج` تُحوَّل تلقائيًا إلى الصفحة الجديدة.

## للمطورين

```
index.html          قائمة النماذج (المعلمات)
form.html?f=<slug>  تعبئة نموذج + معاينة A4 + PDF داخل المتصفح
admin.html          لوحة التحكم (Firebase Auth)
js/firebase-config.js  إعدادات Firebase (الملف الوحيد الذي يُعدَّل قبل النشر)
js/fb.js            طبقة البيانات (Firestore Lite + Auth)
js/pdf.js           إنشاء PDF في المتصفح (SVG foreignObject + jsPDF، تقسيم صفحات مطابق لـ Chromium)
js/pdf-template.js  نماذج PDF: عرض الصفحات (pdf.js)، رسم القيم، وكتابتها على الملف الأصلي (pdf-lib)
js/pdf-detect.js    الكشف التلقائي عن الحقول (حقول تفاعلية، نقاط/شرطات، سطور، خانات جداول، مربعات)
js/pdf-designer.js  محرر نماذج PDF في لوحة التحكم (رفع، سحب، تغيير حجم، إضافة، حذف)
shared/core.js      التحقق + قالب المستند الرسمي (نفس قالب النسخة السابقة)
firebase/firestore.rules  قواعد الأمان
data/initial-data.json    النماذج الأربعة وهوية المدرسة المنقولة من قاعدة البيانات القديمة
vendor/             Firebase JS SDK 13.3.0 و jsPDF 4.2.1 و pdf.js 4.10.38 (legacy) و pdf-lib 1.17.1 (محلية، بدون CDN)
```

بنية Firestore: `forms/{slug}` (المخطط مخزّن كنص JSON)، `site/settings`، `images/{logo|logo2|principalSig|stamp}`، `pdfFiles/{id}` و`pdfFiles/{id}/chunks/{n}` (الملف الأصلي الفارغ لنماذج PDF).

نموذج PDF هو نموذج عادي في `forms` مع `schema.mode = 'pdf'` و`schema.pdfTemplate = { fileId, pages[{w,h,r,m}], color }`، ولكل حقل `box = { p, x, y, w, h }` بالنقاط في فضاء العرض للصفحة.

للتجربة محليًا: `npx serve .` أو `python3 -m http.server` ثم افتحي `http://localhost:8000/` (يجب ربط Firebase أولًا، وإضافة `localhost` موجودة افتراضيًا في Authorized domains).
